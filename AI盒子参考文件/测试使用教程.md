# SpeechRelease 真机测试使用教程（发布包）

本文验收 **本发布包** 内的闭源服务 `SpeechReleaseServer`，验证脚本使用同包内的 **SpeechReleaseClient**（仅 HTTP）。  
系统只需 `python3`（≥3.10），**无需**开发树、venv 或额外 pip 依赖。

---

## 1. 适用场景

| 对象 | 路径 | 说明 |
|------|------|------|
| 语音服务 | `SpeechReleaseServer/` | 闭源可执行文件 + MODELS |
| 验证客户端 | `SpeechReleaseClient/` | 源码 HTTP 客户端 + `scripts/verify_*.py` |

推荐验收顺序（均对接已启动的打包服务）：

1. `/health`
2. 仅唤醒
3. TTS 播报
4. 唤醒 + ASR
5. 完整打断链路

默认端口：`8765`。与源码服务 **不要同时启动**。

---

## 2. 前置条件

### 2.1 产物自检

```bash
ROOT=/path/to/SpeechRelease-aarch64-YYYYMMDD
APP="$ROOT/SpeechReleaseServer"
CLIENT="$ROOT/SpeechReleaseClient"

ls -l "$APP/SpeechReleaseServer"
test -d "$APP/MODELS/asr" && test -d "$APP/MODELS/tts" && echo MODELS_ok
test -d "$CLIENT/scripts" && test -f "$CLIENT/speech_release/client.py" && echo CLIENT_ok
cat "$APP/VERSION.txt" 2>/dev/null || true
cat "$CLIENT/VERSION.txt" 2>/dev/null || true
```

### 2.2 启动打包服务

```bash
cd /path/to/SpeechRelease-aarch64-YYYYMMDD
./启动打包语音服务.sh
# 或
./安装桌面快捷方式.sh   # 生成「SpeechRelease语音服务」图标后再双击
```

### 2.3 健康检查

```bash
curl -s http://127.0.0.1:8765/health | python3 -m json.tool
```

期望：

- `ready=true`
- `provider=real`
- `tts_default_backend` 为 `piper`（默认配置）
- `models.asr_exists` / `keyword_exists` / `piper_exists` 均为 `true`
- `asr_model_dir` 落在 `.../SpeechReleaseServer/MODELS/asr`

日志：可执行文件同目录 `speech_server.log`。

### 2.4 验证脚本环境（包内 SpeechReleaseClient）

```bash
cd /path/to/SpeechRelease-aarch64-YYYYMMDD/SpeechReleaseClient
source ./准备验证环境.sh
# 脚本会设置 PYTHONPATH=本目录，并 cd 到 scripts/
```

说明：

- 仅标准库；系统需有 `python3`
- **仅 HTTP**（默认 `--via http`）；不支持 local 直连
- 也可单独使用独立包 `SpeechReleaseClient-YYYYMMDD/`

### 2.5 交互约定

- 默认唤醒词：**小E同学**（以服务端 `speech_server.json` 的 `wakeup.keyword` 为准）
- 麦克风可用；说完指令后安静约 1 秒
- 打断后需 **立刻** 说第二句指令（默认开口超时约 5 秒，现场可把 `vad.start_timeout_s` 调到 `8`）

用户口令说明见：[用户交互手册.md](./用户交互手册.md)。

## 3. 通用参数

```text
--base-url http://127.0.0.1:8765   # 可改；默认已是该地址
--evidence-output /tmp/xxx.json   # 建议保留证据
```

`--via` 仅接受 `http`（可省略，默认即为 http）。

---

## 4. 分项操作

先执行 2.4 进入 `SpeechReleaseClient/scripts`。

### 4.1 仅唤醒 — `verify_wakeup_keyword.py`

```bash
python3 verify_wakeup_keyword.py --rounds 1 --verbose \
  --evidence-output /tmp/pack_wakeup.json
```

操作：提示后说 **「小E同学」**。  
通过：`passed=true`，`status=recognized`。

### 4.2 TTS — `verify_tts_backends.py`

```bash
python3 verify_tts_backends.py --backend piper
# 可选在线（需外网且服务端 tts.backend 允许）：
# python3 verify_tts_backends.py --backend edge_tts
```

通过：`result.ok=true`，能听到播报。

### 4.3 唤醒 + ASR — `verify_live_client.py`

```bash
python3 verify_live_client.py --rounds 1 \
  --evidence-output /tmp/pack_live_asr.json
```

操作：先说唤醒词，再说短指令（如「今天天气怎么样」）。  
通过：`passed=true`，非空 `instruction`。

### 4.4 打断全链路 — `verify_wakeup_asr_tts_interrupt.py`

```bash
python3 verify_wakeup_asr_tts_interrupt.py --tts-backend piper \
  --evidence-output /tmp/pack_interrupt.json
```

| 步骤 | 操作 |
|------|------|
| step2 | 唤醒词 + 指令 |
| step3 | TTS 播报中再说唤醒词打断 |
| step4 | **不再唤醒**，立刻说第二句指令 |

通过：`passed=true`；step3 通常 `wakeup_seen=true` 且 `tts_interrupted=true`。

## 5. 一键顺序（复制执行）

```bash
ROOT=/path/to/SpeechRelease-aarch64-YYYYMMDD
cd "$ROOT/SpeechReleaseClient"
source ./准备验证环境.sh
mkdir -p /tmp/speech_pack_e2e

python3 verify_wakeup_keyword.py --rounds 1 --verbose \
  --evidence-output /tmp/speech_pack_e2e/wakeup.json

python3 verify_tts_backends.py --backend piper \
  | tee /tmp/speech_pack_e2e/tts.log

python3 verify_live_client.py --rounds 1 \
  --evidence-output /tmp/speech_pack_e2e/live_asr.json

python3 verify_wakeup_asr_tts_interrupt.py --tts-backend piper \
  --evidence-output /tmp/speech_pack_e2e/interrupt.json
```

## 6. 验收清单（打包版）

- [ ] 桌面/脚本可启动 `SpeechReleaseServer`，端口 8765
- [ ] `/health` → `ready=true`，模型在 `SpeechReleaseServer/MODELS`
- [ ] `SpeechReleaseClient/准备验证环境.sh` 可自检通过
- [ ] 唤醒 `verify_wakeup_keyword.py`
- [ ] TTS `verify_tts_backends.py --backend piper`
- [ ] 唤醒+ASR `verify_live_client.py`
- [ ] 打断 `verify_wakeup_asr_tts_interrupt.py`

全部 `passed=true` / `ok=true` 即视为 **打包版 HTTP 全链路** 通过。

## 7. 常见问题（打包版侧重）

| 现象 | 处理 |
|------|------|
| 连不上 8765 | 确认打包服务已起；`fuser -k 8765/tcp` 后重启；勿与源码服务并存 |
| `ready=false` / 模型 missing | 检查 `MODELS/asr`、`MODELS/tts` 是否与二进制同目录 |
| `No module named speech_release` | 先 `source SpeechReleaseClient/准备验证环境.sh` |
| `--via local` 报错 | 客户端仅支持 HTTP；勿传 local |
| 改配置不生效 | 改 exe 旁 `speech_server.json` 后 **重启打包进程** |
| 打断后 `NO_SPEECH_DETECTED` | 打断后立刻说指令；或把配置 `vad.start_timeout_s` 调到 `8` |
